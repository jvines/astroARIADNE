The example scripts live in the repository's
[`examples/` directory](https://github.com/jvines/astroARIADNE/tree/master/examples).
Each one is self-contained: point it at your Python environment with
**ARIADNE** installed and run it. The figures throughout this documentation
were produced by exactly these scripts, so if your output looks different,
something is wrong — please open an issue!
